# Simple Interest Calculator

## Description
This project contains a simple interest calculator that calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Features
- Calculates simple interest
- Easy to use
- Written for learning purposes

## Formula
SI = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time (in years)
